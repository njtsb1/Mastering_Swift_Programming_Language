# Mastering the Swift Programming Language

Project developed during the Santander Bootcamp 2023 - Mobile iOS with Swift, under the guidance of specialist [Robson Moreira](https://github.com/robixnai "Robson Moreira").</br>
In this challenge, you will develop two playground projects using Xcode. For both, you must implement the Object-Oriented Programming paradigm and explore concepts such as control flow, collections, functions, closures, enums, structs, and concurrency.

Challenge Checklist:

- Create two playground projects using Xcode
- Apply the Object-Oriented Programming paradigm to the first project
- Apply the Protocol-Oriented Programming paradigm to the second project
- Explore the following concepts in both projects:
  - Control flow
  - Collections
  - Functions and closures
  - Enums and structs
  - Concurrency

## Project Architecture

The workspace is organized into two primary pillars to isolate architectural paradigms:

- **`POO/Desafio-POO.playground`**: Dedicated environment exploring the Object-Oriented Programming (OOP) paradigm.
- **`POP/Desafio-POP.playground`**: Dedicated environment exploring the modern Protocol-Oriented Programming (POP) paradigm.

## Technical Challenge Checklist

Both playgrounds are implemented to actively explore and demonstrate proficiency in the following core Swift engineering matrices:

- [ ] **Control Flow**: Implementing safe conditional structures (`if-let`, `guard-let`, `switch`) and iteration paradigms.
- [ ] **Collections**: Leveraging complex manipulation of Arrays, Sets, and Dictionaries.
- [ ] **Functions and Closures**: Structuring reusable clean code units and escaping/non-escaping closures block captures.
- [ ] **Enums and Structs**: Modeling immutable value-type records alongside associated data enumerations.
- [ ] **Concurrency**: Handling multi-threaded asynchronous computations safely using modern Swift concurrency frameworks.

## Requirements

- **IDE**: Xcode 14.0+ or compatible compiler
- **Toolchain**: Swift 5.7+
- **Environment**: macOS Playground Sandbox Workspace
