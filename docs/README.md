# Mastering the Swift Programming Language

Project developed during the Santander Bootcamp 2023 - Mobile iOS with Swift, under the guidance of specialist [Robson Moreira](https://github.com/robixnai "Robson Moreira").</br>

## BR Motorsport & Food Portal

A lightweight, fully responsive web application built with clean semantic **HTML5**, modern **CSS3 Custom Properties**, and vanilla **JavaScript**. This landing page celebrates the rich cultural connection between Brazilian heavy-duty racing (Copa Truck / Fórmula Truck) and traditional Brazilian culinary comforts.

## Features

- **Semantic HTML5:** Built entirely with semantic structural components (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) to secure a meaningful document structure.
- **Accessibility (a11y) Focused:** Fully accessible infrastructure featuring high contrast values, dynamic `aria-live` feedback regions, hidden assistive contextual strings (`.sr-only`), and target touch elements matching the **44x44px** standard recommended by WCAG guidelines.
- **Responsive Layout:** Engineered with a robust Mobile-First mindset utilizing flexible Grid structures adapting layouts cleanly across smartphones, tablets, and full desktop displays without the load of heavy external UI frameworks.
- **Dark/Light Modes:** Persisted theme configuration loaded natively through CSS local variables mimicking explicit light (`☀️`) and dark (`🌙`) environments (Dark active by default).
- **Internationalization System (i18n):** Lightweight, multi-language dictionary script delivering dynamic runtime translation support for English (`EN-US` as standard core), Portuguese (`PT-BR`), and Spanish (`ES`).

## Tecnologies used

- **HTML5**: Semantic structure and core markup
- **CSS3**: Core styles, responsive layout rules & theme variables
- **JavaScript**: Light/Dark logic and multi-language engine

## Getting Started

1. Open the file `index.html` directly in any modern standard web browser (Chrome, Edge, Firefox, Safari).
2. Test responsiveness by resizing the browser or viewing via Developer Tools device inspection.
